# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report them privately through GitHub: **Security → Report a vulnerability** on this repository (private vulnerability reporting).

Please include what is affected (Manager / Windows worker / Linux worker, version), how to reproduce it and what an attacker could do. You will get an answer as soon as possible; fixes are released on the `dev` branch first and then in a regular release.

## Supported versions

Only the latest release (and the current `dev` build) receive security fixes.

## Security features

HB Cluster has optional web sign-in, passkeys and worker approval – see [docs/security.md](docs/security.md).
